# Python Turtle Heart ❤️

A layered heart drawn using Python's Turtle graphics.

## 💗 About the Project

This project draws a heart using Python's Turtle graphics
and mathematical equations.

I discovered the original idea through an example on Instagram.
I then experimented with the drawing logic and modified the
code while learning how Turtle graphics works.

This project is part of my journey to learn Python through
small, creative experiments.

## 🛠️ Concepts Explored

- Python nested loops
- The `math` module
- Sine and cosine functions
- Angles and radians
- Coordinate calculations
- Drawing shapes with Turtle graphics
- Debugging Python dependencies

## ⚙️ Requirements

- Python 3
- Tkinter support for Turtle graphics

## 🚀 How to Run

1. Make sure Python 3 and Tkinter are installed.
2. Save the program as `heart.py`.
3. Open a terminal in the directory containing the file.
4. Run:

   `python3 heart.py`

## 🌱 What I Learned

While working on this project, I explored how mathematical
equations can generate shapes, how nested loops can draw
multiple layers, and how to troubleshoot Python dependencies.

I'm continuing to experiment with Python and explore
different ways to draw shapes using code.
